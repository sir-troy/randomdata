Good to know

Plain answers about how the rules work.

What does “Unique” do?

No value appears twice in that column. Number and date ranges are shuffled so each value is used once. Name-like columns get a number added (e.g. “Manila-42”). If the range is too small for your row count, you'll see a message before you continue.

What does “Required” do?

The column is never left blank. Without it, the Blank cells slider (under More) controls how often a cell is empty.

What is a “Key” column?

The row's ID — like a primary key in a database. It's unique, required and always clean. Only one column can be the Key. A Row number or Unique code works best.

How do I limit a column to my own values?

Choose My own list as the data type, then type the values separated by commas — for example Bronze, Silver, Gold, Platinum. Only those values are used, picked at random. Typing a value twice makes it appear more often.

What is “messy” data?

Realistic mistakes for practising data cleaning: extra spaces, random capitals, typos, wrong formats (john@@mail.con), placeholders like N/A, unusual values and broken characters. Unique columns only get extra spaces so they stay unique.

How do repeated rows work?

Never checks every row and replaces any repeat. Add on purpose copies earlier rows but keeps Unique and Key columns different — like the same customer entered twice.

Can Excel open 10 million rows?

No — Excel stops at 1,048,576 rows. For larger files, use a database, Power BI / Power Query, or Python. On Chrome or Edge, turn on Save straight to disk in File format for very large files.

Is my data stored anywhere?

No. Everything is created inside your browser. Nothing is uploaded, and no cookies or browser storage are used. Close the tab and it's gone. Only the feedback form sends what you type into it.
